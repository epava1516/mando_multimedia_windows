Servidor Mando

Descargar servidor · alpha.7

Incluye servidor, bloqueo y componentes de gestos. Hay que instalarlo y emparejar la app una vez.

Conectar al servidor propio

  1. Extrae el ZIP en Windows y sigue las instrucciones de instalación.
  2. Cierra Remote Mouse antes de abrir MandoServer.exe: ambos usan el puerto 1979.
  3. En la app, desconecta y selecciona Mando propio. Pega el código que muestra el PC.

Las pruebas de Windows con URLs y formatos adicionales pasan. La instalación, el navegador y los gestos todavía requieren validación en tu PC. Con el servidor oficial, algunas URLs pueden devolver «sin texto».
