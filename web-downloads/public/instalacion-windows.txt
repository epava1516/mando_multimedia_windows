MANDO — INSTALADOR WINDOWS

1. Descarga MandoSetup-0.5.0-alpha.10.exe y abrelo con doble clic.
2. Acepta el permiso de administrador para instalar el servicio local de bloqueo.
3. Al terminar, cierra Remote Mouse y abre Mando Server desde Inicio con tu cuenta normal.
4. La IP se detecta automaticamente. Si hay varias redes, selecciona tu Wi-Fi o Ethernet de casa.
5. En la app: Desconectar → Buscar en Wi-Fi → Mando propio → pega el codigo mando1 que muestra el PC → Conectar.

No necesitas instalar Python, extraer el ZIP ni ejecutar comandos de PowerShell.

Cerrar la ventana deja Mando funcionando en la bandeja del sistema. Doble clic en el icono abre el codigo; Salir detiene el servidor. No arranca automaticamente al iniciar Windows. La red de casa debe estar configurada como privada.

PORTAPAPELES
Copia directamente texto o una URL del navegador. Android → Teclado → Portapapeles → PC → movil. Luego pega en el movil. Solo texto, maximo 1000 unidades UTF-16, con Windows desbloqueado.

DESINSTALAR
Configuracion de Windows → Aplicaciones → Mando Server. Conserva la identidad y autorizaciones en LocalAppData; no se borran tus datos de emparejamiento.

ESTADO
Version experimental. Hay pruebas automatizadas de instalacion, actualizacion y desinstalacion. Los gestos y la pantalla bloqueada requieren validacion en tu PC.
